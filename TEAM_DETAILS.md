## 🎯 Team Objective
To develop a secure, responsive, and user-friendly campus marketplace that enables students and staff to buy, sell, and exchange products within the college community through a modern web application with real-time communication features.

---

## 🛠️ Technologies Used
- **Frontend**: React.js, Vite, HTML5, CSS3, JavaScript (ES6+), Lucide Icons
- **Backend & Database**: Supabase (PostgreSQL), RESTful API
- **Realtime Communication**: Supabase Realtime Channels & Subscriptions
- **Version Control**: Git, GitHub
- **Deployment**: Vercel Live Deployment
