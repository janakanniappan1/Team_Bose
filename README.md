## ✨ Key Features & Capabilities

- 🔐 **Campus Authentication**: Secure login & signup for verified campus students and faculty.
- 🛍️ **Live Marketplace Feed**: Real-time listing grid with category filtering, search, and condition tags.
- 💬 **Real-time 1-to-1 Chat**: Production WhatsApp-grade 2-column messaging system powered by Supabase Realtime subscriptions.
- ⚡ **Instant Dynamic Updates**: Products and messages update live across all connected clients instantly without manual page refreshes.
- 🏷️ **Instant Price Offers & Negotiation**: Send direct price offers to sellers within active conversations.
- 📊 **User Dashboard Hub**: Manage profile, active listings, wishlist, purchase history, and account settings.

---

## 🛠️ Technology Stack

- **Frontend**: React.js, Vite, HTML5, CSS3 (Cozy Neutral Retreat Design Tokens), Lucide Icons
- **Backend & Database**: Supabase (PostgreSQL), RESTful Data Services
- **Realtime Services**: Supabase Realtime Channels & WebSocket Subscriptions
- **Hosting & Deployment**: Vercel Live Production Deployment

## 🚀 How to Run Locally

### 1. Clone the repository
```bash
git clone https://github.com/janakanniappan1/Team_Bose.git
cd Team_Bose
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start development server
```bash
npm run dev
```
Open `http://localhost:5173/` in your browser.
